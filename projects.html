Marketo · Campaign attribution

Marketo Lead Uploader

Objective: Recover campaign information from trusted sources and enrich existing Marketo lead records to support more complete attribution reporting.

Solution: Validate CSV columns against writable Marketo lead fields, preview records, update existing leads in batches and download failed rows. The update-only workflow skips blank cells and does not create new leads.

Technology: Marketo REST API and CSV. Updating lead fields does not automatically recreate historical touchpoints or guarantee a Marketo Measure attribution recalculation.

Adobe Tags · Configuration review

Tags Audit

Objective: Bring an Adobe Tags estate into one view, from Launch properties and rules to data elements, extensions and libraries.

Solution: A dashboard with a review queue, configuration-readiness checks, structural resource comparisons, a property explorer and JSON or Excel exports.

Technology: Adobe Experience Platform Tags (Launch) and the Adobe Reactor API. Readiness scores guide configuration reviews; they do not verify browser tag execution or runtime performance.

Adobe Analytics · Direct data collection

Direct Data Insertion: GET & Edge Network

Objective: Test and prototype Analytics data collection from server-side systems or platforms without a client-side SDK.

Solution: Construct and validate requests, review equivalent cURL commands and inspect responses through separate GET and Edge Network workflows.

Technology: Adobe Analytics Data Insertion API (GET) and the Adobe Experience Platform Edge Network API. The Edge workflow sends payloads directly without loading the Web SDK library. A successful HTTP response still requires end-to-end ingestion validation.

Adobe Analytics · Bulk ingestion

Bulk Data Insertion API (BDIA)

Objective: Bring historical datasets, offline events and warehouse exports into Adobe Analytics through a controlled batch ingestion workflow.

Solution: Validate CSV structure and report suite IDs, gzip files, generate SHA-256 idempotency keys, check for duplicates and run Adobe validation before upload. Review upload receipts, invalid rows and processing status rather than treating HTTP success as completed ingestion.

Technology: Adobe Analytics Bulk Data Insertion API, vanilla JavaScript, native browser Compression and Crypto APIs, and a Node.js/Express proxy for OAuth Server-to-Server authentication and API requests.
